产品概述

Y&M ACU 是一款专为汽车动力系统设计的智能控制单元，基于 STM32F103 主控芯片，配合 Nextion 串口触摸屏实现本地操作，同时通过 ESP32-C6 提供WiFi 无线控制面板，支持手机、平板等移动设备远程监控与调试。

双路泵控 PWM MAF 空气流量采集 Flex Fuel 乙醇传感器 排气阀 AT/MT 控制 智能喷淋系统 WiFi AP 模式 CSV 数据记录 多告警保护 支持 Defi 仪表 快速校准模式 双串口 OTA 固件更新 进一步优化ACU控制盒的PCB体积，最终体积仅为iPhone4的2/3

硬件架构

  • 主控：32 位控制芯片 STM32（机器人主流控制器），72MHz Cortex-M3
  • 显示屏：4.2 寸 Nextion TFT 彩色触摸屏（480×320）
  • WiFi 模块：ESP32-C6，支持 802.11ax
  • 供电：DC 12V（汽车电瓶）
  • 通信：USART2→屏幕(230400bps)，USART3→ESP32(115200bps)

控制对象

  • Pump A / Pump B：两路 PWM fuel pump 控制
  • Exhaust Valve：排气阀 GPIO 控制（PB14）
  • Spray：喷淋系统 GPIO 控制（PB15）
  • DAC1/DAC2：PA4/PA5 模拟输出（0~3.3V）
  • 4 路模拟输入 + 2 路模拟输出：支持接入 Defi 仪表
📺

Nextion 串口屏（本地操作）

安装在驾驶舱内的 3.5" 彩色触摸屏，提供主页、设置页、出厂页三个界面。所有参数修改、模式切换、手动控制均可在屏幕上完成。

📶

ESP32 WiFi（远程操作）

ESP32 WiFi（远程操作）

ESP32 创建 WiFi 热点，手机浏览器访问即可查看实时数据和修改设置。Display 页展示运行状态，Setting 页远程调参，支持 CSV 数据导出。

产品亮点

⚡

双路独立泵控 + TEST 模式

Pump A / Pump B 各自拥有独立的起跳阈值、满量阈值和使能开关。支持 TEST 模式直接设定泵输出占空比，便于台架调试和故障排查。

🌡️

Flex Fuel 乙醇传感器

支持 GM 风格 Flex Fuel 传感器（50~150Hz），实时解析乙醇含量（0~100%）和燃油温度。乙醇含量通过 DAC 模拟输出至 ECU，实现自动调整点火 Map。传感器未插入时自动显示 "-"，避免误读。

🔧

排气阀 AT/MT 双模式 + 延迟关闭

AT 模式：根据 MAF 频率自动开关排气阀。MT 模式：手动按钮直接控制。状态灯始终反映阀门实际 IO（非软件变量），并支持 EX_DELAY 延迟关闭防止频繁开关。

🌧️

智能喷淋 + 透明度状态联动

支持设定开启/关闭时长，主开关使能后自动循环。rainSwith 按钮透明度直观反映使能状态（127=使能，50=失能），RainStat 始终读取实际 IO。

📊

WiFi 实时数据面板

ESP32 创建 "ACU Center" WiFi 热点，手机连入后访问 192.168.4.1 即可查看实时数据。200ms 刷新间隔，无需安装 App。

📈

CSV 数据记录 + 下载进度

6000 条循环滚动存储（约 10 分钟），100ms 采样间隔，写满后自动覆盖最早数据。只记录使能的泵，节省内存。点击 Stop Record 下载 CSV，全屏遮罩显示旋转动画和实时 KB 数。

💡

三级自动亮度 + Bright 联动

LightSen=0 手动模式，Bright 滑条直接控制。LightSen=1/2/3 为自动挡位，分别对应 LEVEL1/2/3_VAL 三档系数。自动模式下 Bright 框透明度置灰（aph=50），显示当前 dim 值。

⚠️

多重告警保护 + 轮切显示

液位低、电瓶过压（>14.8V）、电瓶欠压（<11V）三项告警。屏幕端 1 秒轮切图标，WiFi 端红色告警条，ESP32 和屏幕同步推送。

🏎️

支持 Defi 仪表

4 路模拟输入 + 2 路模拟输出（DAC），可直接接入 Defi 仪表，实时采集和输出模拟信号，兼容市面主流改装仪表。

🎯

快速校准模式

出厂页提供一键自动校准，MAF / ETH / AFR 校准系数自动计算并写入 Flash。输入 2.5V 标准电压即可完成精度校准，无需手动计算。

🔄

双串口 OTA 固件更新

使用双串口通道，支持同时一键更新双设备固件，让 OTA 不再繁琐，升级维护更高效。

📱

超小体积

进一步优化 ACU 控制盒的 PCB 体积，最终体积仅为 iPhone4 的 2/3，安装灵活，适配更多车型空间。

一、Nextion 屏幕操作

Nextion 串口屏是 ACU 的本地操作终端，安装在驾驶舱内，通过 USART2（230400bps）与 STM32 通信。屏幕端操作不依赖 WiFi，即使没有手机也能独立完成所有控制。

屏幕端特点： 响应速度快、操作直观（触屏点击）、掉电后设置自动保存（Flash 存储）。适合行驶中快速查看状态和紧急操作。

1.1 主页（page0）

显示区域：

  • 顶部按钮行：Pump1/Pump2 使能状态灯（绿=使能，红=未使能）、Spray 喷淋开关、Ex Valve 排气阀状态、AT/MT 模式切换。
  • FUEL STATE（左栏）：Ethanol% 乙醇含量（0~100%），通过 DAC 模拟输出至 ECU 实现自动调整点火 Map；Fuel Temp 燃油温度。传感器未插入显示 "-"。
  • AIR FLOW（中栏）：MAF 空气流量大号数字显示，支持 Hz / mV 单位切换。下方两根进度条分别显示 Pump A/B 占空比。
  • PUMP LOGIC（右栏）：Pump1/Pump2 的 Start（起跳）和 Full（满量）阈值，Spraying Operate/Idle 喷淋时间参数。
  • 底部横幅：Honda Racing 品牌标识。
  • 告警图标：液位低（FluidIco）、电瓶过压（hiIco）、电瓶欠压（lowIco）三个图标同位置，多告警时每秒轮切显示。
屏幕端交互：
点击 Spray 图标 → 切换喷淋主开关（SPRAYMAIN）。使能后状态灯根据实际情况显示绿灯（喷射中）/ 红灯（未喷射），未使能则图标置灰，默认关闭。
点击 MT/AT 图标 → 切换排气模式。AT 模式下 Ex Valve 图标置灰不可操作，由 MAF 自动控制排气阀；MT 模式下点击 Ex Valve 图标手动控制。状态灯根据实际情况显示绿灯（开启）/ 红灯（关闭）。
进度条：AIR FLOW 区域下方两根进度条分别实时显示 Pump A 和 Pump B 的喷量（PWM 占空比 0~100%），上方第一条为 Pump A（绿色），下方为 Pump B（蓝色）。
点击右下角 → 进入设置页

1.3 出厂页（FactorySetting）

注意：出厂页仅用于技术人员校准，普通用户请勿随意修改！参数仅在进页时发送一次（lightsensor 除外，每 500ms 刷新）。
  • mafvadj / ethvadj / afrvadj：电压校准系数。输入标准 2.5V 后点击自动校准按钮，系统自动计算系数并写入 Flash。公式：coeff = 2500 × 40950000 / (3300 × ADC)
  • level1 / level2 / level3：亮度三级挡位系数，默认 23/25/27。公式：dim = AD_LIGHT_SENS × LEVELx / 100
  • dac1_adj / dac2_adj：DAC 输出校准系数（×/10000）
  • version：当前固件版本号
  • lightsensor：光敏传感器 ADC 原始值（0~4095，实时刷新）

二、ESP32 WiFi 操作

ESP32-C6 模块作为 ACU 的无线扩展终端，通过 USART3（115200bps）接收 STM32 广播的 Nextion 显示数据，解析后在网页端实时呈现。WiFi 端适合远程监控、参数微调、数据记录导出，不需要物理接触屏幕。

WiFi 端特点： 无需安装 App（纯网页）、支持手机/平板/电脑、数据记录导出 CSV、200ms 实时刷新。适合台架调试时工程师在旁观察，或副驾驶位乘客协助监控。

2.1 连接步骤

1

连接 WiFi 热点

打开手机/平板 WiFi，搜索热点 ACU Center，输入密码 acu666666 连接。

2

打开浏览器访问

浏览器地址栏输入 http://192.168.4.1，自动加载控制面板。支持 Chrome、Safari、Edge 等现代浏览器。

3

实时监控与操作

Display 页查看实时数据，Setting 页修改参数，LOG 区记录和导出数据。所有数据每 200ms 自动轮询刷新。

2.4 LOG 数据记录与导出

核心特性：6000 条循环滚动存储，100ms 采样间隔，总时长约 10 分钟。写满后自动覆盖最早数据，始终保持最近 10 分钟的运行记录。只记录使能的泵，未使能的泵列自动跳过，节省内存和 CSV 空间。
1

开始记录

点击 Start Record（绿色按钮），按钮变灰，系统开始 100ms 间隔记录。6000 条循环滚动，约 10 分钟，写满后自动覆盖最早数据。

2

运行中记录

6000 条循环滚动存储（约 10 分钟），100ms 采样间隔，写满后自动覆盖最早数据。只记录使能的泵，未使能的泵跳过以节省内存和 CSV 空间。

3

停止并下载

点击 Stop Record（红色按钮），弹出全屏遮罩 + 旋转动画 + 实时 KB 数显示，完成后自动下载 CSV。

四、使用指南

4.1 首次上电

  1. 接通 12V 电源，系统自检后自动进入屏幕主页
  2. 屏幕显示 MAF、泵状态、排气模式等实时数据
  3. ESP32 自动创建 "ACU Center" WiFi 热点（约 5 秒后可用）
  4. 如需修改参数，可在屏幕上操作或手机连 WiFi 访问网页

4.2 设置泵参数（屏幕端）

  1. 屏幕主页 → 点击右下角 设置齿轮 → 进入设置页
  2. 找到 Pump A / Pump B 分组，设定 Start 和 Full 阈值
  3. 打开 Enable 使能开关
  4. 点击 SAVE 保存，参数自动写入 Flash 掉电保存

4.3 设置泵参数（WiFi 端）

  1. 手机连接 ACU Center WiFi，浏览器访问 192.168.4.1
  2. 点击顶部 Setting Tab 进入设置页
  3. 修改 Pump A / Pump B 的 Start / Full / Enable 参数
  4. 点击底部 SAVE SETTING 按钮下发至 STM32

4.4 排气阀操作

屏幕端：
AT 模式：系统自动根据 MAF 控制阀门，无需干预
MT 模式：点击 chimneySwitch 图标手动开关
切换模式：点击 ATMT 图标
WiFi 端：
AT 模式：系统自动控制，Ex Valve 按钮置灰不可点
MT 模式：点击 Ex Valve 按钮手动开关
切换模式：点击 AT / MT 按钮

4.5 亮度调节

  • 手动：设置页 LightSen 设为 0，拖动 Bright 滑条（0~100）。此时 Bright 框不透明（aph=127）
  • 自动挡位 1/2/3：LightSen 设为 1/2/3，系统根据环境光自动计算 dim。Bright 框变灰（aph=50）不可编辑，数值显示当前实际 dim
  • 挡位系数微调：进入出厂页修改 level1/2/3 值（默认 23/25/27），值越大同光照下屏幕越亮

4.6 数据记录导出

  1. WiFi 端 Display 页 → 找到 LOG 区域
  2. 点击 Start Record（绿色按钮）开始记录，100ms 采样间隔
  3. 运行中可继续操作其他功能，记录后台进行
  4. 点击 Stop Record，弹出下载遮罩，显示旋转动画和已下载 KB 数
  5. 下载完成后浏览器自动保存 acu_log.csv，可用 Excel 分析

五、故障排除

现象可能原因解决方法
WiFi 连不上ESP32 未启动或距离过远检查 ESP32 供电，靠近设备重试
泵无输出Enable 未打开 / Start 阈值过高进入设置页打开 Enable，适当降低 Start 值
排气阀不响应处于 AT 模式 / MT 模式但按钮被禁用切换到 MT 模式后操作，或检查 EX_REV 设置
乙醇显示 "-"传感器未插入或频率异常检查传感器连接，确认频率在 50~150Hz 范围
告警图标闪烁液位低 / 电瓶电压异常检查冷却液液位，测量电瓶电压是否在 11~14.8V
设置保存后无效未点击 SAVE / Flash 写保护确保点击 SAVE 按钮，检查 Flash 扇区是否正常
下载 LOG 卡顿数据量大，传输需要时间等待进度条完成，6000 条约需 5~10 秒
屏幕和 WiFi 状态不一致ESP32 串口数据丢失或延迟检查 USART3 接线，重启 ESP32 模块
注意事项：
  • 修改出厂页参数前请备份原始值，错误的校准系数会导致传感器读数偏差
  • ISP 烧录时建议选择"局部擦除"，避免 Flash 中的用户设置被清除
  • 长时间不使用建议断开电源，避免电瓶亏电
